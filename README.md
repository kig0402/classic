## 🆕 주요 개선 및 수정 사항 (v2)

1. **가독성 극대화 폰트 전면 개편**:
   - 명조체(세리프)를 완전히 걷어내고 모바일 디바이스에서 가장 깔끔하고 선명한 **Pretendard(프리텐다드) & Plus Jakarta Sans** 폰트를 적용했습니다.
2. **매일 자정 갱신되는 [오늘의 클래식 도슨트 Pick]**:
   - 오늘 날짜(예: `🌟 11월 24일 오늘의 클래식 도슨트 Pick`)에 맞추어 매일 자정 새로운 클래식 명곡과 비하인드 스토리가 자동으로 순환 갱신됩니다.
3. **하단 5대 탭바 터치 & 부드러운 스크롤 완벽 연동**:
   - `[홈]`, `[무드]`, `[소믈리에]`, `[작곡가]`, `[테마]` 터치 시 해당 위치로 부드럽게 스크롤되며, 소믈리에 터치 시 질문 입력창이 자동 포커스됩니다.
   - 현재 화면 위치에 맞춰 하단 탭 아이콘의 골드 활성화 불빛이 자동으로 전환(ScrollSpy)됩니다.
4. **최상단 통합 검색창 즉시 반응 및 작곡가 검색**:
   - 곡명(월광, 운명, 녹턴 등)뿐만 아니라 작곡가(베토벤, 쇼팽, 모차르트, 바흐 등) 검색 시 해당 작곡가의 **대표 명곡 1위~5위가 우선 정렬**되어 검색 결과 배너와 함께 즉시 표시됩니다.
   - 입력 시 즉각 반응하며, `Enter` 키 또는 돋보기 버튼을 누르면 검색 결과 영역으로 즉시 스크롤됩니다.
5. **감정과 분위기별 큐레이션 즉각 피드백**:
   - 각 감성 태그(새벽 감성, 깊은 몰입, 비 오는 날 등) 터치 시, 해당 테마 배너(`[아이콘] [무드 이름] 큐레이션 (X곡)`)가 생성되며 해당 명곡 리스트로 바로 전환됩니다.
6. **작곡가별 대표 명곡 큐레이션 대폭 보강**:
   - 베토벤(월광, 운명, 엘리제를 위하여, 합창, 비창)
   - 쇼팽(녹턴 9-2, 빗방울, 즉흥환상곡, 이별의 곡)
   - 모차르트(아이네 클라이네, 피아노 협주곡 21번, 터키 행진곡, 라크리모사)
   - 바흐(G선상의 아리아, 무반주 첼로 1번, 토카타와 푸가)
   - 드뷔시(달빛, 아라베스크)
   - 차이콥스키(백조의 호수, 꽃의 왈츠) 등 총 18대 대표곡 수록
